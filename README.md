# 🐍 EID LAB

## IT Infrastructure & Cybersecurity Portfolio

EID LAB is my personal hands-on IT laboratory built to develop and demonstrate practical skills in system administration, networking, and cybersecurity.

The lab is built using VMware Workstation and will include Windows Server, Windows clients, Linux systems, networking, security configuration, and troubleshooting.

## 🖥️ Lab Environment

- VMware Workstation
- Windows Server 2022
- Windows 10
- Ubuntu Linux
- Kali Linux

## 🎯 Project Goals

- Build an IT infrastructure from scratch
- Configure and manage Windows Server environments
- Practice networking and troubleshooting
- Manage Windows and Linux systems
- Apply security hardening techniques
- Document real hands-on work with screenshots and explanations
